# 🏭 Paperware Factory Website

A modern, high-performance React website built with Vite and Tailwind CSS.

Original Figma design: https://www.figma.com/design/7xx7P9l2j5ItpnGzk0QL0R/Paperware-Factory

## 🚀 Quick Start

### Development
```bash
npm install
npm run dev
```
Visit `http://localhost:5173`

### Production Build
```bash
npm run build
npm run preview  # Preview production build locally
```

## 🌐 Deploy to Live (লাইভ করুন)

### Option 1: One-Click Deploy (সবচেয়ে সহজ)
```bash
./deploy.sh
```

### Option 2: Manual Vercel Deploy
```bash
npm install -g vercel
vercel --prod
```

### Option 3: GitHub + Vercel Dashboard
1. Push to GitHub
2. Go to https://vercel.com/new
3. Import your repository
4. Click "Deploy"

📖 **Full deployment guide:** See `DEPLOYMENT_GUIDE.md` for detailed instructions in Bangla and English.
